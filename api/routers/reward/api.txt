# 미션등록 
외부 파트너사에서 정답 미션을 등록합니다.

인증 필요: API Key + HMAC-MD5 서명

타임스탬프 유효 기간: 5분

이미지 업로드
이미지 업로드는 multipart/form-data 형식으로 전송합니다.

mnc_img: 메인 이미지
ma_img1 ~ ma_img10: 힌트 이미지

조회 post 요청
/api/v1/mission/read

등록된 정답 미션을 조회합니다.

인증 필요: API Key + HMAC-MD5 서명

타임스탬프 유효 기간: 5분

검색 조건 (선택)
mnc_idx: 미션 IDX로 단건 조회
search_title: 제목으로 검색
search_memo: 메모로 검색
검색 조건 없음: 해당 파트너가 등록한 전체 미션 조회
서명 생성
mnc_idx로 검색: api_key + secret_key + timestamp + mnc_idx
search_title로 검색: api_key + secret_key + timestamp + search_title
search_memo로 검색: api_key + secret_key + timestamp + search_memo
전체 조회: api_key + secret_key + timestamp
응답 형태
1건 조회 시: type: "single", data는 객체
2건 이상 조회 시: type: "list", data는 배열
