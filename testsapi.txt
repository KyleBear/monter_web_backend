2. 주요 응답 필드
================================================================================

각 검색 결과 항목은 다음 필드를 포함합니다:

- title: 상품명 (HTML 태그 포함 가능, 예: <b>HJC</b>)
- mallName: 쇼핑몰명 (예: "옥션", "쿠팡", "G마켓", "HJC스토어")
- link: 상품 링크 (형식이 쇼핑몰마다 다름)
- productId: 네이버 통합 상품 ID (nvmid)
- lprice: 최저가
- hprice: 최고가
- brand: 브랜드명
- maker: 제조사명
- category1~4: 카테고리 정보
- productType: 상품 유형 (1: 가격비교 상품, 3: 일반상품 등)

5. 중요한 발견 사항
================================================================================

1. 같은 상품이 여러 쇼핑몰에서 판매되면 각각 별도의 검색 결과 항목으로 반환됨
   - 각 항목은 고유한 productId (nvmid)를 가짐
   - 같은 상품이라도 쇼핑몰마다 다른 nvmid를 가질 수 있음

2. link 필드의 형식이 쇼핑몰마다 다름
   - 네이버 쇼핑/스마트스토어: 직접 링크 (상품 ID 추출 용이)
   - 쿠팡/G마켓: 네이버 리다이렉트 링크 (상품 ID는 파라미터에 포함)

3. 쇼핑몰별 상품 ID 추출 방법
   - 옥션: link에서 직접 추출 불가 (네이버 카탈로그 링크만 제공)
   - 쿠팡: link의 itemId 파라미터에서 추출 가능
   - G마켓: link의 item-no 파라미터에서 추출 가능
   - 스마트스토어: link의 /products/{product_id} 패턴에서 추출 가능
   - 11번가: 이번 테스트 결과에는 없었지만, 일반적으로 /products/{product_id} 패턴

4. mallName으로 쇼핑몰 구분 가능
   - "옥션", "쿠팡", "G마켓", "11번가" 등으로 명확히 구분됨

7. URL 패턴 정리
================================================================================

[11번가]
- 패턴: https://www.11st.co.kr/products/{product_id}
- 정규식: 11st\.co\.kr/products/(\d+)
- 예시: https://www.11st.co.kr/products/7844692722

[G마켓]
- 패턴: https://item.gmarket.co.kr/Item?goodscode={goodscode}
- 정규식: [\?&]goodscode=(\d+)
- 예시: https://item.gmarket.co.kr/Item?goodscode=4254268378
- 네이버 링크: https://link.gmarket.co.kr/gate/pcs?item-no={item_no}

[옥션]
- 패턴: https://itempage3.auction.co.kr/DetailView.aspx?itemno={itemno}
- 정규식: [\?&]itemno=([A-Z0-9]+)
- 예시: https://itempage3.auction.co.kr/DetailView.aspx?itemno=E832249308

[쿠팡]
- 패턴: https://www.coupang.com/vp/products/{product_id}
- 정규식: coupang\.com/vp/products/(\d+)
- 예시: https://www.coupang.com/vp/products/9868702055
- 네이버 링크: https://link.coupang.com/re/PCSNAVERPCSDP?itemId={item_id}

[스마트스토어]
- 패턴: https://smartstore.naver.com/{channel_id}/products/{product_id}
- 정규식: (?:smartstore|brand)\.naver\.com/[^/]+/products/(\d+)
- 예시: https://smartstore.naver.com/main/products/11239695451

[네이버 쇼핑 카탈로그]
- 패턴: https://search.shopping.naver.com/catalog/{nvmid}
- 정규식: search\.shopping\.naver\.com/catalog/(\d+)
- 예시: https://search.shopping.naver.com/catalog/56318602799

8. 결론
================================================================================

네이버 쇼핑 검색 API는:
- 여러 쇼핑몰의 상품을 한 번에 검색할 수 있음
- 각 쇼핑몰의 상품을 별도 항목으로 반환
- mallName으로 쇼핑몰 구분 가능
- link 필드는 쇼핑몰마다 다른 형식 (직접 링크 또는 리다이렉트 링크)

실제 쇼핑몰 직접 링크를 얻으려면:
- 네이버 쇼핑 검색 API로 검색
- mallName으로 필터링
- link에서 상품 ID 추출 (가능한 경우)
- 직접 링크가 필요한 경우 각 쇼핑몰 사이트 크롤링
